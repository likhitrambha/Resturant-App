🚀 Features
Dynamic restaurant menu fetched from API
Responsive mobile and desktop design
Slidable dish category tabs
Cart functionality with live item count updates
Increment and decrement quantity controls
Displays “Customizations available” for dishes with addons
Protected routes with login authentication
Reusable and maintainable component structure
📋 Functional Requirements
Dish categories and dishes rendered dynamically from API
Tabs are generated dynamically based on API response
Cart count updates when clicking + and -
Addon dishes display customization message
User-friendly and visually appealing interface
Hosted online for public access
🛠️ Technologies Used
React JS
React Router DOM
Context API
JavaScript (ES6)
CSS3
